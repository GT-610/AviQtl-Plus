# Native Color Effects

This package demonstrates an installable `aviqtl-wgsl-v1` Effect.

`color_tint` samples the current layer, mixes its RGB channels with a configurable color, and preserves the source alpha. The Amount and Color controls use the same metadata-driven Slint parameter editor and keyframe system as built-in effects.

Install the repository ZIP through the package manager, or copy this directory to `<AviQtl Data>/effects/com.aviqtl.effects.color/` during development.

See the parent [native render package guide](../README.md) for the metadata and WGSL contract.
